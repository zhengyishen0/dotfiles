# Karabiner-Elements Config

Config is symlinked, so changes in Karabiner UI automatically update dotfiles.

## Contents

### Simple Modifications (SANWA BT51)
- fn (globe) → left_control
- grave_accent_and_tilde (`) → escape
- left_command ↔ left_option (swap)

### Complex Modifications
- **Ctrl+HJKL** → Arrow keys (all devices)
- **Option+Up/Down** → 5 lines in WeChat/Feishu
- **Right Option + letter** → Open apps (SANWA BT51 only)
  - W: WeChat
  - V: VS Code
  - C: Chrome
  - G: Ghostty
  - F: Lark/Feishu
